## Demo Project - Cloud & IAAS Basics

Create server and deploy java based application on AWS.

### Technologies Used:
AWS, Linux, Java, Gradle

### Project Description:

- Setup and configure a server on AWS (Deploying EC2 Instance)
- Create and configure a new linux user on EC2 Instance (Security best practice)
- Build the Java application using Gradle
- Then deploy the app on EC2 server  and run a Java Gradle application on remote server (AWS EC2 Instance)
- Access EC2 instance from local Desktop using RSA key pair
- Open the firewall rules on AWS EC2 Instance for particular port to run the Java based app remotely on the browser using public IP of EC2 Instance
