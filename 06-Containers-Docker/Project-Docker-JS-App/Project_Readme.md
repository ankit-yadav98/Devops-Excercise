## Demo Project - Containers with Docker

- Use Docker for local development
- Docker Compose - Run multiple Docker Containers
- Dockerize Nodejs application
- Persist data with Docker Volumes

## Technologies used:

Docker, Nodejs, MongoDB, MongoExpress

## Project Description:
- Create Dockerfile for Nodejs application and build Docker image and then push the first version of the created app image to aws ECR (Elastic Container Registry).
- Run Nodejs application in Docker container and connect to MongoDB database container locally.
- Also run MongoExpress container as a UI of the MongoDB database.
- Build Docker compose file to run MongoDB and MongoExpress Containers.
- Persist data of a MongoDB container by attaching a Docker volume to it.
